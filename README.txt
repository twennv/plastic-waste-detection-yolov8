**Projet PIC 2024-2025 – Détection de déchets aquatiques par IA - EILCO Saint-Omer**

--------------------

Contributeurs :

(1) LEBOURG Antoine

(2) BIN KHAIRIL AZREEN Khairil-Danial

(3) EL-KHIATE Zineb

--------------------

Ce programme a été développé dans le cadre d’un projet PIC visant à détecter automatiquement les déchets plastiques en surface de rivière, dans le but de mieux contrôler la pollution plastique dans les mers et océans.

--------------------

Il utilise le modèle YOLOv8, entraîné sur une base de données issue du projet Deep Plastic :
https://github.com/TianlongJia/deep_plastic

--------------------

Les images ont été annotées manuellement sur Roboflow :
https://universe.roboflow.com/pic2024/pic_2024

--------------------

Le modèle est entraîné pour reconnaître 4 classes de déchets :
- Autre plastique
- Bouteille plastique
- Non plastique
- Sac plastique
